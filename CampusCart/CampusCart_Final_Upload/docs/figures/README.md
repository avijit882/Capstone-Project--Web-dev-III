# Figure assets

The PNGs in this folder are rendered from the accompanying Graphviz `.dot` source files. They are architecture/data-flow illustrations, **not screenshots of a running API or proof that runtime tests passed**.

- `campuscart-architecture.png`: route/controller/service/model and real-time components.
- `campuscart-data-model.png`: MongoDB collections and references.
- `campuscart-checkout-flow.png`: transaction and rollback flow.
- `campuscart-realtime-flow.png`: EventEmitter, persistent notification and Socket.IO flow.
